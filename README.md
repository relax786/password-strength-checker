# Password Strength Checker

A beginner-friendly Python program that checks the basic strength of a test password.

## Features

- Checks password length
- Checks lowercase letters
- Checks uppercase letters
- Checks numbers
- Checks symbols
- Detects a few common passwords
- Does not save or transmit passwords

## Requirements

- Python 3.8 or newer

## Run the program

```bash
python password_checker.py
```

On some systems:

```bash
python3 password_checker.py
```

## Important note

Use this program for learning and testing only. Do not enter passwords that you use for real accounts.
